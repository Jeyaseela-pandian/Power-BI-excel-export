Strongest first. A correct table beats a chart that only looks similar: a visual becomes an Excel chart only when the chart keeps its meaning.
Fidelity. High: reads the same as in Power BI. Medium: the same data and colours, drawn differently. A dash: nothing to export.
Two modes. Data tables mode writes every data visual as an Excel Table; Charts mode turns the native chart types into Excel charts, with their data on a hidden sheet.

Known limits

  • Totals are filled only where adding the rows gives Power BI's total (sums, counts, min / max); ratios, averages and distinct counts stay blank.
  • Table sparklines need permission to query the semantic model (Build); without it a note names them.
  • New-card reference labels appear when Power BI includes them in the export.
  • Not yet confirmed on the live Power BI service: the sparkline queries and reference labels.
